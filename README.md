# Bridgology

Desktop software for analysing ground-penetrating radar (GPR) surveys of concrete
and masonry structures.

## Download

Get the latest version from [Releases](../../releases/latest):

- **macOS** (Apple Silicon): `Bridgology-<version>-macos-arm64.dmg`
- **Windows** (64-bit): `Bridgology-Setup-<version>-windows-x64.exe`

The app checks for new versions itself (Help ▸ Check for Updates…).

## Editions

Without a licence key, Bridgology runs as the free **Viewer**: open and view
projects you receive. Enter a licence key (Help ▸ Licence Key…) to unlock
**Pro**. Contact [Bridgology](https://www.bridgology.com) to buy a licence.
